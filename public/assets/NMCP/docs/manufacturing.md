# NMCP Manufacturing Notes

Represented as fabricable at SME scale — no single-piece stamping.
- Plate: waterjet/laser-cut S355 blank, perimeter chamfer machined, face-milled surface
- Hub pockets: CNC-bored recesses, 20 deg draft; pressed gold retaining rings; potted LED; glass lens
- Channels: CNC-milled (power conduit, logistics etch, corridor datum)
- Pedestal: welded 80mm SHS frame, bolt-down base, bolted service panels
- Boundary simplified to 10mm so all features are machinable at the plate's own resolution
